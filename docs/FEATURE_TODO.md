# 功能路线与后续待办清单

> 状态：2026-07-27 第一阶段受控重建已完成
> 说明：`[x]` 表示当前代码、测试和公开文档已经形成闭环；`[ ]` 是明确延期或尚未实现的能力。

## 1. 项目定位

- 第一目标：作为工程化爬虫项目展示，功能真实可用、测试充分、容易解释。
- 第二目标：满足个人长期归档知乎内容的需要。
- 使用者包括希望研究项目架构的开发者，以及希望由 Codex 等 Agent 代为执行命令的普通用户。
- 在当前仓库重建，不保留旧接口兼容层，也不维护 TUI、云端账号或前端构建系统。

## 3. 输出结构

只有“整个专栏”使用批量目录：

```text
知乎归档/
├── zhihu.db
└── 机器学习/
    ├── 机器学习.md
    ├── 机器学习.html
    ├── 内容/
    │   ├── 一文归纳AI数据增强之法.md
    │   ├── 一文归纳AI数据增强之法.html
    │   └── ...
    ├── media/
    └── assets/
```

- [x] 专栏同名文件保存简介和按年份分组的完整目录
- [x] 使用“本栏目共 N 篇”
- [x] 文章页提供收录专栏、本次归档来源、返回目录和上一篇/下一篇导航
- [x] 不使用 `index.md` 或 `index.html`

单篇文章、单个回答、整个问题和独立视频使用精简结构：

```text
标题/
├── 标题.md
├── 标题.html
├── media/
└── assets/
```

问题下的回答作为章节合并进同一个问题文档，不创建 `内容/`。`media/` 和 `assets/` 没有对应产物时不会创建。文件名优先可读，同时处理同名、三个系统的保留名称、字符长度和 UTF-8 字节长度。

## 4. 已确定默认值

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| Markdown | 开 | 生成可读 `.md` |
| HTML | 开 | 生成离线 `.html` 和本地 CSS |
| SQLite | 开 | 整个归档共用根目录 `zhihu.db` |
| 媒体下载 | 开 | 图片、动图、封面、独立视频 |
| PDF | 关 | 尚未实现，开启时明确报错 |
| 评论 | 关 | 可通过设置或 `--comments` 开启 |
| 一级评论 | 10 | 不足 10 条时保存全部 |
| 每条二级回复 | 10 | 不足 10 条时保存全部 |
| 浏览器回退 | `auto` | HTTP/API 失败或载荷无效时回退 |
| 代理 | 关 | 配置后应用于 HTTP、管理浏览器和媒体 |
| 原始 JSON 输出 | 无 | 不提供 |

独立视频固定选择已知尺寸最大的清晰度，不额外询问；保存原始链接、媒体元数据与本地路径，支持 `.part` 断点续传、有界重试和长度校验。同一媒体在不同归档中允许各自保留。

正文图片、动图或封面单项失败时，正文、SQLite 和其余媒体继续归档，失败项以结构化警告返回并保留普通远程链接；未下载资源不会作为远程图片或视频自动加载。独立视频主文件失败仍明确终止该次视频归档。

## 5. 抓取与浏览器链路

- [x] HTTP/API 优先，分页直到接口结束
- [x] 对 200 但字段缺失或正文为空的载荷进行校验并回退
- [x] 项目管理的持久化浏览器回退
- [x] 系统 Chrome 不可用时回退到项目管理的 Chromium
- [x] 可选 CDP 连接本机已登录 Chrome，且只允许本机控制端点
- [x] Cookie 文件加载、HTTP → 浏览器与浏览器 → HTTP 回流
- [x] 真实登录状态检查，不输出 Cookie 值
- [x] HTTP、媒体和浏览器使用统一代理入口，日志隐藏凭证
- [x] HTTP 禁止跨域自动重定向；媒体逐跳校验 URL，任意外部域拒绝私网 DNS，知乎 HTTPS CDN 兼容代理 fake-IP DNS
- [x] 超时、有界重试、退避、Range 续传和资源关闭边界
- [ ] 面向大规模批量任务的全局并发、请求间隔和抖动策略
- [ ] Cookie 加密存储和引导式重新登录

项目不承诺“模拟真人”或绕过访问限制；目标是稳定、低负载地归档用户有权访问的内容。

## 6. SQLite 与确定性关系

当前数据库已经保存可从来源直接确认、可追溯的关系：

- [x] 文章 `收录于` 专栏
- [x] 回答 `回答了` 问题
- [x] 内容 `由……创作` 作者
- [x] 内容 `拥有` 评论
- [x] 二级回复 `回复` 一级评论
- [x] 内容或评论 `包含` 媒体
- [x] 内容 `拥有封面`
- [ ] 内容 `链接到` 其他已归档内容

重复归档同一内容会替换本轮明确获取的派生状态，清理对应的过期评论、媒体和关系，避免幽灵边；SQLite 是可靠的归档数据层，但当前不等同于全文搜索或知识图谱产品。

未启用评论/媒体下载表示本轮未请求该可选数据，不会删除旧数据：已有评论会恢复到可读文档，仍存在的本地媒体路径会继续复用。只有显式抓取到的新线程（包括空线程）才替换旧评论状态。
