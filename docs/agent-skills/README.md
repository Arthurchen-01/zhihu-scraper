# Project Agent Skills

本目录存放本仓库专用的项目内 skills。它们不是全局 Codex skills，不应安装到 `~/.codex/skills`；后续代理进入仓库后，先读 `CONSTITUTION.md` 和 `AGENTS.md`，再按任务选择这里的 `SKILL.md`。

## 选择规则

- 维护冻结、范围判断：`freeze-maintenance/SKILL.md`
- CLI/TUI 命令面：`command-surface/SKILL.md`
- 配置、Cookie、运行时路径：`config-runtime/SKILL.md`
- Markdown、图片、SQLite 保存链路：`save-pipeline/SKILL.md`
- 抓取 payload 与 typed contracts：`scraper-contracts/SKILL.md`
- README、英文 README、治理文档同步：`docs-sync/SKILL.md`
- Textual TUI 工作台：`tui-maintenance/SKILL.md`

这些 skill 只展开任务型流程，不覆盖 `CONSTITUTION.md` 的最高治理地位，也不复制 `AGENTS.md` 的完整规则。
