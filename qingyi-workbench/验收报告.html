4 本地执行器是什么、怎么用

这就是你问的「本地工具」。它是一个 单文件 Python 脚本： qingyi_executor.py（v5 现为 66,284 字节 / 语法校验通过； 执行器的写入逻辑没变，只是执行顺序改成「先取云端稿子 → 原样上传 → 最后请求云端复核」）。

4.1 它是什么

一句话：它是唯一真正去改知乎文章的程序，运行在你自己的电脑上。 云端（zh.samuraiguan.cloud）只负责检索、排任务、收进度，不碰写入通道。
项目说明
文件形态单个 .py 文件，自包含，无需安装任何本项目代码
唯一依赖pip install requests（就这一个第三方库）
运行环境你电脑上任意 Python 3.8+；Windows / macOS 都能跑
它做什么轮询云端领任务 → 逐篇改标题+正文 → 每篇写完立即回报进度
它不做什么不改专栏归属、不改话题、不改评论设置、不动图片、不动发布状态
备份每篇改动前，原文自动存到你本机备份目录，可一键还原

4.2 怎么用（三步）

① 下载：在工作台页面点「下载执行器」，或直接取
   https://zh.samuraiguan.cloud/api/qy/executor/script  →  存为 qingyi_executor.py

② 放凭证：在同一个文件夹里新建 cookie.txt，粘贴你的知乎 Cookie
