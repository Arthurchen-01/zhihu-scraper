# 清一新教育 · 修改助手（浏览器扩展）

把本浏览器里已登录的知乎凭证，自动同步到清一新教育控制台的凭证柜。

**它解决的那一个问题**：浏览器会独占锁定自己的 Cookie 数据库，外部程序在浏览器开着时
读不到知乎登录态，所以旧流程要你「先关掉浏览器」。装了这个扩展之后，**不用关了**。

---

## 给用户：怎么装

最省事的方式是把整个文件夹丢给你自己的 AI Agent，让它按 `AGENTS.md` 装。

手动装也很简单：

1. 双击 `install-extension.ps1`
   （或右键 → 使用 PowerShell 运行；Chrome 用户加参数 `-Browser Chrome`）
2. 脚本会把扩展放到固定位置、把路径放进剪贴板、并打开扩展管理页
3. 在该页面上：
   - 打开右上角 **开发者模式**
   - 点 **加载解压缩的扩展**
   - 地址栏 **Ctrl+V** 粘贴路径 → 回车
4. 点工具栏上的扩展图标，看到「本浏览器知乎登录：已登录」就成功了

装好后点一下「立即同步到云端」。以后双击「清一新教育」一键程序即可，**浏览器不用关**。

---

## 它到底做了什么

```
扩展读取本浏览器知乎 Cookie
        ↓  POST /api/qy/credential-deposit
控制台凭证柜（内存，6 小时 TTL，不落盘）
        ↓  GET  /api/qy/credential-latest
一键修改程序取用凭证 → 开始修改文章
```

- 只在**本机**读 Cookie，浏览器内部行为，不涉及任何破解；
- 上传的是知乎发给本机的登录凭据，不是账号密码；
- 每次浏览器启动、登录态变化、以及每 30 分钟自动刷新一次，保证凭证不过期。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单：权限（cookies / storage / alarms）、图标、入口 |
| `config.js` | 站点地址、密钥、存储键名（后台与界面共用） |
| `background.js` | 核心：读 Cookie → 上报云端；定时与登录态变化时自动重跑 |
| `popup.html` / `popup.js` | 点图标后的面板：状态 +「立即同步」 |
| `options.html` / `options.js` | 设置：站点地址、密钥、刷新间隔、自动同步开关 |
| `help.html` | 给用户看的白话说明 |
| `install-extension.ps1` | 安装助手（放文件、开页面、进剪贴板） |
| `AGENTS.md` | 给用户 AI Agent 的部署说明书 |
| `icons/` | 16 / 32 / 48 / 128 图标，由 `../brand/make_icon.py` 生成 |

## 权限说明（为什么需要）

| 权限 | 为什么 |
| --- | --- |
| `cookies` + `*://*.zhihu.com/*` | 读本浏览器的知乎登录态 —— 这是它存在的全部理由 |
| `https://zh.samuraiguan.cloud/*` | 把凭证送到控制台凭证柜 |
| `storage` | 记住站点地址、密钥、上次同步结果 |
| `alarms` | 定时自动刷新凭证 |

没有 `tabs`、没有 `<all_urls>`、不注入任何页面脚本、不监听浏览历史。

## 排障

| 现象 | 处理 |
| --- | --- |
| 显示「未登录」 | 装到了没登录知乎的浏览器；换到已登录的那个重装 |
| 403 | 设置页把密钥改回 `guanjun2026` |
| 连不上控制台 | 设置页确认地址为 `https://zh.samuraiguan.cloud` |
| 图标消失 | 扩展文件夹被移动/删除了，重新「加载已解压的扩展」 |

## 注意

**Chrome / Edge 禁止任何脚本注入 `chrome://extensions` / `edge://extensions` 页面**，
所以最后那 2~3 下点选必须由人完成 —— 这是浏览器刻意设的防注入限制，无法用代码绕过。
`install-extension.ps1` 已经把其余的一切都代劳了。

如果需要**完全零点击**的体验，唯一的合法途径是上架官方应用商店。
